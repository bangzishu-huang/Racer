# Racer
A game the revolves around cars racing around a race track. A simple yet entertaining game that is inspired by Formula 1. It's supposed to be a single player game where you are versing a computer car and trying to win in a car race. You have to navigate through loops and avoid colliding with the wall as you would be bounced back.

Through creating Racer, I learned how to import assets whether it be pixel structures or png images in general, and also learned about pixel blocking. I also was able to learn how to make and set the coordinates for which the computer car was going to follow throughout the different levels, as well as learning about how to apply the wall bounce when the player collides with it. This was an amazing opportunity for me to just further test my python skills and have more practice.

# Tech Stack
- Frontend: Python
- Hosting: GitHub Pagez
- Version Control: GitHub
- Development Tools: Visual Studio Code, Pygame-CE, Pygbag

# Features
A couple of features in Race include:
- 3 different levels of play (Easy, Medium, Wonky)
- Settings bar in order for the player to adjust their top speed and bounce back volume
- Lap counter and a timer for how long your lap takes
- Unique but confusing race during the "Wonky" mode
